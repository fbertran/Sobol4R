# Sobol4R 0.1.0

* Package creation and initial release containing stochastic Sobol estimators,
  autoplot helpers, and reliability utilities inspired by Zhu and Sudret (2021).
* Added uncertainty-aware `summarise_sobol()` output class and matching
  `autoplot()` method with bootstrap error bars.
* Added `sobol4r_reliability()` to recycle stored samples into failure-indicator
  Sobol indices and document the workflow in the vignette.
